# SleepHealth-Analytics

## 📌 Project Overview
SleepHealth-Analytics is a data science project focused on analyzing sleep quality through **Exploratory Data Analysis (EDA)**, **Multiple Regression**, and **Time Series Analysis with ARIMA models**. The objective is to identify how lifestyle habits and morning routines influence sleep health, while detecting trends and forecasting future behavior.

This project combines statistical modeling, predictive analysis, and data visualization to generate useful insights related to wellness, rest, and daily habits.

---

## 🎯 Objectives
- Perform exploratory analysis to understand the dataset structure and variables.
- Analyze factors associated with sleep quality.
- Apply **Multiple Linear Regression** to evaluate the impact of explanatory variables.
- Use **ARIMA Time Series Models** to identify patterns, trends, and forecasts.
- Explore relationships between sleep health and morning routines.
- Present interpretable results through visualizations.

---

## 📊 Techniques Used
- Exploratory Data Analysis (EDA)
- Descriptive Statistics
- Correlation Analysis
- Multiple Linear Regression
- Time Series Analysis
- ARIMA Modeling
- Data Visualization
